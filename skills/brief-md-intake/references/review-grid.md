## Expected sections per file

| File | Expected sections |
|---|---|
| 01-company | Identity, business, offer, business model, key figures, organization and decision-making, history, values, tools |
| 02-project | Goal, trigger, scope included and excluded, deliverables, success criteria, deadlines, budget, decision-maker, history, dependencies |
| 03-customers | Segments (2 to 4), verbatims, customers not targeted, current journey |
| 04-market | Positioning, direct competitors (3 to 5 named), indirect competitors, differentiation, trends, references, seasonality |
| 05-brand | Mission, personality, tone of voice, what the brand is not, existing assets, reference content, words to use and avoid |
| 06-pains-doubts | Frustrations, past failures, doubts, fears, internal tensions, things left unsaid |
| 07-constraints | Budget and deadlines, technical, legal, internal resources, approvals, non-negotiables, access to provide |
| 00-summary | Index, 5 key points, to verify, missing, sensitive data |

A section that is present but contains only `[unknown]` counts as empty.

## Signs of a generic text

A file is probably generic if several of these signs add up:
- No figures, no dates, no names of products, places or competitors
- Marketing adjectives without proof ("innovative", "customer-centric", "high quality", "passionate")
- Sentences interchangeable from one company to another, so that you could replace the name without changing anything
- Customer verbatims without a source, too polished, or all praising
- File 06 without any real doubt (everything is fine, no failure, no tension)
- All the information labelled `[confirmed]` while the content is vague (a cosmetic label)

A file 06 that is too positive is a strong signal, because a sincere brief almost always contains some friction.

## Contradictions to look for

| Type | Example |
|---|---|
| Budget, scope, deadline | Broad scope, short deadline, tight budget |
| Ambition and figures | A strong growth goal set against stagnant revenue or a minimal headcount |
| Target and market | Target segment absent from the market described, or competitors who target something else |
| Brand and pains | A "warm and approachable" tone set against complaints about a cold service |
| Decision-maker and organization | A final decision-maker in file 02 who does not appear in file 01, or two decision-makers |
| Figures across files | The same data point with two different values |
| Constraints and deliverables | An imposed tool incompatible with an expected deliverable |
| Dates | Milestones that cannot follow one another |

For each contradiction, quote the two passages (file and section), name what is at stake, and do not decide.

## Common blind spots

Check that the brief answers these questions, depending on the type of project:
- Who really decides, and who can block?
- Which competitors are named, and which are missing?
- What has already failed, and why?
- What access (data, accounts, content) will be provided, and by whom?
- What measure will say that the project has succeeded?
- Are accessibility, data protection or intellectual property mentioned when the project calls for them?
- Who, on the client side, will be available during the project, and for how much time?
- What happens if the budget or the deadline changes?

## Sensitive data to report

Do not copy it into the framing, and report only the file and the nature of the data:
- Names of natural persons (employees, customers, patients)
- Health data, personal financial situation, private life
- Login details, passwords, access keys, account numbers
- Information covered by a confidentiality agreement or belonging to a third party
